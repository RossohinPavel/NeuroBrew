# NeuroBrew

Сварим крафтуху вместе с нейроновыми.


## Идея

NeuroBrew — open-source менеджер Agent Skills для разработчиков, работающих с AI-агентами. Он решает узкую практическую задачу: позволяет сохранить полезный skill один раз, организовать такие skills в переиспользуемые наборы и затем подключать нужную конфигурацию к другим проектам через MCP или локальную синхронизацию. Вместо ручного копирования файлов между репозиториями NeuroBrew выступает единым source of truth для агентного контекста.

Продукт ориентирован на техническую аудиторию и следует философии небольших Unix/Linux-инструментов: минимум лишней магии, предсказуемое поведение и качественное решение одной конкретной задачи. Бренд NeuroBrew отсылает к craft brewing — разработчик собирает рабочую конфигурацию из уже подготовленных компонентов, комбинируя skills под конкретный проект, стек или тип задачи.
