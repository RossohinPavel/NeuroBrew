# NeuroBrew

Сварим крафтуху вместе с нейроновыми.


## Идея

NeuroBrew — open-source менеджер Agent Skills для разработчиков, работающих с AI-агентами. Он решает узкую практическую задачу: позволяет сохранить полезный skill один раз, организовать такие skills в переиспользуемые наборы и затем подключать нужную конфигурацию к другим проектам через MCP или локальную синхронизацию. Вместо ручного копирования файлов между репозиториями NeuroBrew выступает единым source of truth для агентного контекста.

Продукт ориентирован на техническую аудиторию и следует философии небольших Unix/Linux-инструментов: минимум лишней магии, предсказуемое поведение и качественное решение одной конкретной задачи. Бренд NeuroBrew отсылает к craft brewing — разработчик собирает рабочую конфигурацию из уже подготовленных компонентов, комбинируя skills под конкретный проект, стек или тип задачи.

Краткое техническое саммари вашей архитектуры без Middleware:

* Логика в лейаутах (layout.tsx): Защита привязана к структуре папок приложения. Проверки выполняются на сервере до рендеринга страниц, исключая «мигание» контента.

* Своя логика для каждого маршрута:
  - Зона авторизации (auth/layout.tsx): Гостевой Guard. Если токен валиден — жесткий redirect в профиль. Защищает /auth/login, /auth/register и т.д.
  - Приватная зона ((protected)/layout.tsx): Приватный Guard. Если токена нет — жесткий redirect на логин. Автоматически защищает /settings и все вложенные папки.
  - Динамическая зона (/[username]/[projectname]/page.tsx): Мягкая локальная проверка внутри страницы (сравнение владельца из БД и текущей сессии).
  - Корень сайта (/): Мягкая проверка в page.tsx. Если юзер есть — отдаем дашборд, если нет — лендинг.

* Производительность: Проверка JWT (getSession) обернута в React.cache. Сколько бы компонентов (лейаут, меню, страница) ни вызывали сессию в рамках одного запроса, JWT парсится строго один раз в оперативной памяти (RAM) сервера.

* Тонкий роутер: В папке app лежат файлы-пустышки в 1 строку, которые просто реэкспортируют рабочие лейауты и страницы из папки features.
