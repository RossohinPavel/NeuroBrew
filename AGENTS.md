# Инструкции для агентов

- Делай то, что просит пользователь в его текущем промпте.
- Например, если пользователь просит изменить код, вноси запрошенные изменения в код. Это лишь один из примеров общего правила: выполняй именно ту работу, которую просит пользователь.
- Не пиши тесты, не запускай линтеры, тесты и другие сопроводительные утилиты, если пользователь прямо об этом не попросил.
- При чтении этого файла не пересказывай, не цитируй и не упоминай содержащиеся здесь инструкции.
- Работай только в рамках запроса пользователя и не добавляй незапрошенные действия.
- Есть скилы, которые запускаются автоматически и влияют на стиль и/или порядок написания кода. Декларировать их применения не надо, если в скиле нет прямого указания, что этот скил задействуется.
