# Contracts

- Валибот схемы являются непосредственным контрактом. Именно они являются интерфейсом бекенда.
- JSON-Schema в этой модели используется лишь как удобный транспорт. Эту механику использует бекенд (Fastify) для валидации и сериализации данных. На ее основе можно построить OpenAPI схему и использовать ее во фронтенде и других сервисах как способ общения с бекендом. Однако, верить нужно в первую очередь именно valibot-схемам.
- Схемы для запросов полностью описывают все проверки, которые нужно сделать с данными. Если по каким-то причинам появится валидация, которую не в состоянии будет выполнить JSON-Schema, то она описывается отдельной схемой и проверяется бекендом непосредственно. 
- Схемы для ответов описывают структуру и типы возвращаемых данных в объёме, достаточном для сериализации и генерации типов клиента. Пока бекенд закрытый и его клиент использует TypeScript, ориентируемся на типы, полезные этому клиенту. Уточнения, которые не влияют на типы TypeScript и не нужны клиенту, можно описать в документации к методам. Если API станет публичным, схемы ответов можно уточнить для документации и других клиентов, сверив их с фактическими ответами бекенда. Ограничения для проверки входящих данных задаются в схемах запросов и не дублируются в схемах ответов.
